# Project93 - EasyX 圆盘指针绘制项目

## 📌 项目简介
这是一个基于 **EasyX 图形库** 开发的 C/C++ 项目，实现了一个动态圆盘指针效果，可作为学习图形编程、基础动画逻辑的入门示例。

## ✨ 功能特性
- 动态绘制圆盘指针，支持基础旋转动画
- 使用 EasyX 图形库，开发简单、易上手
- 纯 C/C++ 实现，无需复杂依赖

## 🛠️ 环境要求
- Windows 系统
- Visual Studio / Dev-C++ / CodeBlocks 等支持 C/C++ 的编译器
- 已安装 [EasyX 图形库](https://easyx.cn/)
